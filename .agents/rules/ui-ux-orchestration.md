# Antigravity UI/UX Skill Orchestration Rules

When assisting with user interface planning, frontend architecture, design systems, styling, or UX evaluation, activate the appropriate specialized skills based on the task scope and target stack:

1. **General UI/UX Design & Architecture**:
   - Primary orchestrator: `product-design-director` (enforces 6-step workflow, 3-concept exploration, token architecture).
   - Design intelligence: `ui-ux-pro-max` (domain search, palettes, font pairings, chart types).
   - Visual aesthetics: `frontend-design` (distinctive layouts, intentional typography, non-generic craft).

2. **React Native & Expo (Mobile)**:
   - Screen structure & HIG: `expo-native-ui`.
   - Routing & navigation: `expo-router`.
   - Motion & gestures: `expo-animation`.
   - Mobile design system & tokens: `expo-design-system`.
   - Native SwiftUI & Jetpack Compose primitives: `expo-ui`.

3. **React & Next.js (Web)**:
   - Architecture & performance: `vercel-react-best-practices` (or `react-best-practices`).
   - Web interface guidelines & accessibility: `web-design-guidelines`.

4. **UI Quality Audit & Review**:
   - Comprehensive review: `ui-quality-auditor` (6-dimension audit, 100-point rubric, prioritized actionable fixes).

**Execution Discipline**:
- Activate skills progressively on demand; do not load unnecessary skills.
- Reject generic AI design clichés (unmotivated gradients, repetitive 3-column cards, emoji icons in production UI).
- Prioritize accessibility (WCAG AA), responsive behavior, and clean component architecture.
