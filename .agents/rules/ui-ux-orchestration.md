# Antigravity UI/UX & Motion Skill Orchestration Rules

When assisting with user interface planning, frontend architecture, design systems, styling, UX evaluation, or mobile motion design, activate the appropriate specialized skills based on the task scope and target stack:

1. **General UI/UX Design & Architecture**:
   - Primary orchestrator: `product-design-director` (enforces 6-step workflow, 3-concept exploration, token architecture).
   - Design intelligence: `ui-ux-pro-max` (domain search, palettes, font pairings, chart types).
   - Visual aesthetics: `frontend-design` (distinctive layouts, intentional typography, non-generic craft).

2. **React Native & Expo (Mobile Screens & Layout)**:
   - Screen structure & HIG: `expo-native-ui`.
   - Routing & navigation: `expo-router`.
   - Mobile design system & tokens: `expo-design-system`.
   - Native SwiftUI & Jetpack Compose primitives: `expo-ui`.

3. **React Native & Expo (Motion Design & Interactions)**:
   - Motion orchestrator: `eparly-motion-director` (coordinates restrained, fluid, native motion preserving approved editorial styles).
   - Native implementation: `expo-animation` (Reanimated worklets, Gesture Handler, 60/120fps UI runtime).
   - Interaction engineering: `react-native-design-engineering` (press feedback, card transitions, sheet physics).
   - Apple platform principles: `apple-design-react-native` (direct manipulation, springs, material depth, haptics).
   - Opportunity discovery: `find-react-native-animation-opportunities` (read-only candidate evaluation).
   - Review & audit: `review-react-native-animations` (evidence-backed reviews) and `improve-react-native-animations` (systemic project audits).
   - Vocabulary lookup: `react-native-animation-vocabulary` (reverse lookup for mobile motion terms).

4. **React & Next.js (Web)**:
   - Architecture & performance: `vercel-react-best-practices` (or `react-best-practices`).
   - Web interface guidelines & accessibility: `web-design-guidelines`.

5. **UI Quality Audit & Review**:
   - Comprehensive review: `ui-quality-auditor` (6-dimension audit, 100-point rubric, prioritized actionable fixes).

**Execution Discipline**:
- Activate skills progressively on demand; do not load unnecessary skills.
- Reject generic AI design clichés (unmotivated gradients, repetitive 3-column cards, emoji icons in production UI).
- Prioritize accessibility (WCAG AA), responsive behavior, and clean component architecture.
